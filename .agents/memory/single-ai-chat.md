---
name: Single AI chat surface
description: Wearwell's product decision to keep one conversational AI entry point on mobile.
---

Use one assistant chat surface for Wearwell mobile. Route brief refinement and post-brief questions through the primary chat rather than introducing a second planning interview or follow-up panel. Mobile must use the shared interview service and deterministic wardrobe scorer. The assistant may explain only scored outfit items or the real available pieces and missing categories; it must not invent closet combinations.

**Why:** The user clarified that the focus is mobile and that mobile should use the same pipelines and functionality as the web app.

**How to apply:** Keep one mobile chat entry point. Reuse shared interview/scoring logic, pass only concise scored outfit or gap context to AI, and keep wardrobe results grounded in the actual scorer output.
